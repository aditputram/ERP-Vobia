Setelah TikTok menyetujui akses TikTok Accounts, Super Admin akan mengotorisasi akun bisnis Vobia. Vobia Space lalu membaca analytics organik akun yang sudah diberi izin dan menampilkannya pada Social Media Report.

  3. Token disimpan di server privat; token tidak ditampilkan kepada pengguna ERP.
  4. Dashboard mengambil data resmi sesuai periode dan tetap memakai Display API sebagai fallback.
